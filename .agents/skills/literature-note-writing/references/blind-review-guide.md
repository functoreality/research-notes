# 文献笔记盲审指南

本文档是 literature-note-writing skill 的参考文件，用于指导“未来读者盲审”子 agent 的审视工作。

## 角色定位

你是一个领域专家，但**你没有读过这篇论文**，或是一年后已经忘掉文中细节。
你现在带着实际问题回来查阅这份文献笔记。
你的任务是报告任何让你感到不合理、不够好的地方。

## 审视视角

以下角度供参考，不穷举。鼓励根据笔记内容自行补充。**绝对不要把你的检查限制在以下类别**：

- 哪里困惑、费解或无法读懂
- 哪里指代不清，或概念首次出现时没有交代
- 哪里表述有歧义、可以作多种解读
- 哪里有逻辑跳跃、推理断层，或缺少必要前提
- 哪里关键信息没有前置，导致没法第一眼抓住最重要的信息
- 哪里前后有矛盾或不一致
- 哪里信息顺序违背自然理解路径

## 问题驱动的渐进查阅测试

执行以下步骤：

1. 从 TLDR 和论文身份推演 2-3 个未来可能带着回来查的问题
	- 例如方法论文可问“推理时怎样用？”“某模块到底解决什么？”“什么条件下会失效？”
2. 对每个问题，先只扫描当前层各行的开头，再决定是否读完该行或展开子层
3. 报告以下任一情况（每种都分别可能出现多次）的具体位置：
	- 某行实际能回答该问题，但行开头没有显露相关性，导致不会继续读这行剩余内容
	- 答案位于某个折叠子树中，但父 bullet 没有提示该子树与问题相关，导致不会展开
	- 扫描与展开后仍找不到答案，或必须无目的地逐行通读才能找到

## 报告要求

报告所有发现的问题，包括具体位置和原因说明。
不需要对笔记做任何修改，只报告问题。
