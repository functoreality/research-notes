## 二、三个候选重组方案

### 方案 A：四段式重排（推荐）

按"心智 → 流程 → 要素规范 → 检查"线性阅读重排：

```
1. 笔记的本质（合并 §1 心态精华 + §5 开头）
   - 思考记录不是摘录；深度由价值决定；篇幅与质量无关
   - 与论文对话（评注/critique 是核心价值，不是附加）

2. 阅读与组织（合并 §0.1 阅读阶段 + §0.2 + §5.1/5.2/5.3）
   - 带着三个问题读
   - 核心洞察的层次选择（理论/实验/方法/质疑驱动四种展开方式）
   - 围绕核心洞察组织骨架

3. 撰写笔记（合并 §0.3 + §3 TLDR + §2 全部 + §4 风格部分）
   3.1 骨架与 TLDR 设计
       - TLDR 写法（场景→目的→手段；§3 整段并入）
       - 骨架 bullet：行首回查线索（合并 §0.3 step3 + §2.1）
       - 父子层次标注（合并 §0.3 step3 + §2.1 末段）
   3.2 内容要素
       - 关键数据 + 标注出处（合并 §0.3 step5+6 + §2.6）
       - 引文：压缩安全网（合并 §0.3 step7 + §2.4）
       - 评注（合并 §0.3 step8 + §2.5）
       - 重新框定（合并 §0.1 末段 + §2.7）
       - 比较时拆分正交维度（§2.8 不变）
   3.3 写作风格
       - 极致压缩（合并 §2.3 + §1 风格定位）
       - 归因判断而非解释（合并 §1 段 + §2.5 末段）
       - 不解释已知概念 / 解释论文特有概念（§1 整理）
       - 取舍指南（§1 "不是在写参考文档"那段独立成节）

4. 笔记格式（§4 + §2 数学符号、标注出处格式并入）
   - 文件结构与行格式、tab 缩进
   - 标点：全角、不用粗体/斜体强调术语
   - 数学符号（行内 LaTeX）
   - 不用第三人称表述

5. 复核阶段（§0.4 整理，去重后剩真正新条目）
   - 自检清单（只保留"训练侧/推理侧""读起来不像给自己写"等独有项）
   - 脚本检查（保留表格作为脚本能力索引）
   - 第三方审视 + 修订循环
```

**优点**：去重彻底、序号与心智模型一致、读者线性读完即可上手  
**代价**：439 行需要全面重排，老章节序号会变（如果你记得"§2.4 引文"这种位置就要重新熟悉）

### 方案 C：双层结构（心法篇 + 程序篇）

```
A. 心法篇（思维/原则）
   A1 笔记本质 / A2 综合优先 / A3 极致压缩与风格 / A4 重新框定 / A5 对话与 critique
```
