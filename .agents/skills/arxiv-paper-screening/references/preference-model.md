# 本项目的论文价值偏好

## 金标准

分级参考两类证据，不能把它们压成单一金标准：

- 本文件中的校准例凝聚了历史 S/A/B/C，反映时间稀缺时的主观阅读优先级，
  是恢复等级边界的主要依据。
- 若用户提供后续阅读或笔记写入结果，它反映论文是否确实产生过可记录内容，
  但会受可用时间影响，只用于发现可能被粗筛低估的技术要素。

后续写入笔记不意味着论文应获得高优先级，未写入也不意味着没有价值。
Skill 应优先复现用户的时间分配意图，再利用可用的实际记录修正明显漏判。

## 用户的研究位置

用户是面向 PDE 基础模型的通用算法研究者，当前特别关注以计算图编码 PDE 的
路线。目标不是替某个具体工程应用挑选最好用的求解器，而是建立能够跨方程、
跨物理、跨几何和跨离散设置迁移的方法与知识框架。

笔记以“一个技术要素解决什么问题”组织。最有价值的论文通常能补充以下至少
一类内容：

- 为已有目的提供一种新的、非平凡且可迁移的手段。
- 让已知手段服务于此前没有识别出的新目的。
- 暴露现有框架遗漏的子问题，或提示框架组织维度需要调整。
- 提供足以改变已有判断的反例、负面结果、失效机制或定量规律。
- 提供可公开使用、适合预训练混入或 benchmark 比较的数据。

## 高优先级研究信号

### 1. PDE 基础模型的核心能力

- 如何表示方程、算子项、变量、边界条件、几何和离散信息。
- 如何组合单项、单方程或单物理模块，处理未见方程和耦合系统。
- 如何从上下文识别动力学，进行 in-context、zero-shot 或 test-time adaptation。
- 如何设计多方程、多物理、多维度或多分辨率的联合预训练。
- 如何分析预训练覆盖、迁移边界、灾难性遗忘和 OoD 失败。
- 基础模型的数据构成、scaling law、训练和部署成本。

这里的 PDE/ODE 基础模型是一个共享模型处理多个不同 PDE、ODE 系统或物理
系统，而非针对每个系统单独训练。只在同一 PDE 下改变初边值、系数、区域或
分辨率的模型，按普通神经算子判断。标题使用“基础模型”不能改变这一分类。

S 的准入范围是封闭的：多 PDE 基础模型及其直接研究，以及对多 PDE 预训练或
评测有直接价值的公开数据集。普通神经算子和 PINN 无论多新颖都最高为 A。
对于确属多 PDE 基础模型的论文，漏掉的损失高于收入少量假阳性的阅读成本，
因此通常收入 S。

模块化路线不要求一个单体网络包办所有 PDE。若预训练的算子项模块可跨 PDE
重新组合，且新 PDE 无需整体重训，它同样属于基础模型核心路线。直接研究
跨系统预训练、in-context 泛化或迁移机制的论文也可进入 S，但普通 OoD
实验不能借此越过大类上限。

基础模型按实质而非论文自称判断。训练阶段不绑定具体方程、推理时才通过
PDE 残差、上下文或条件处理多种未见方程的共享模型，也属于 S 候选。

### 2. 神经算子的通用瓶颈

- 场、几何、方程和多变量物理的表示及 token 化。
- 不规则区域、散点、拓扑变化和跨离散泛化。
- 局部与全局交互、多尺度和高分辨率计算的成本矛盾。
- 含时预测的误差累积、稳定性、时间分辨率和长时 rollout。
- 数据稀缺、数据生成、主动选样、自监督和物理信息训练。
- 边界条件、守恒律、频谱性质和其他结构先验的施加方式。
- 反问题、系统识别、UQ 与正问题模型之间可复用的联系。

普通神经算子以 B 为基线。普通架构替换、标准组件组合或仅刷新 benchmark
数字的论文通常不能进入 A。若其结构直接解决表示、跨离散泛化、规模、数据、
长时稳定性等核心瓶颈，并能抽象为其他模型可复用的非平凡原则，才升为 A。
PINN 以 C 为基线，只有机制能迁移到更一般框架时才上调。

A 表示延后阅读可能影响近期基础模型研究决策，不等于“以后可能写进主笔记”。
普通 NO 即使有清楚的新机制，若短期错过的损失不大，仍放 B。但在已经通过
总入选关的论文中，重要 NO、优化或反问题技术在 A/B 难分时可选 A。

### 3. 横向的 ML 与数值分析原则

用户会记录不局限于 AI-for-PDE 的一般机制。例如：

- 表示学习、优化器行为、课程学习、集成与概率预测之间的关系。
- 传统数值方法与学习方法的分工、混合和误差尺度关系。
- 生成模型中间态的正则性、约束施加和后验采样机制。
- 对模型失效、鲁棒性和评估指标的系统诊断。

这类论文主题不属于 S 的准入范围。一个强的横向原则可以使 B/C 主题的论文
上调到 A，但不能越过 S 的大类上限。

## 特殊内容的判断

### 数据集与 benchmark

公开可用且与 PDE/物理场相关的数据有独立价值。优先考虑：

- 能用于多方程或多物理预训练的数据集。
- 覆盖真实复杂几何、边界、障碍物、变量配置或高分辨率场的数据集。
- 系统比较 OoD、分辨率、长时稳定性或失效模式的 benchmark。

仅在单一狭窄应用中自建、未公开的数据通常不能因“有数据”获得高等级。
公开的单 PDE 数据集若规模、精度或任务设置具有明显稀缺性，通常为 A；普通
小型数据集为 B 或不列入。覆盖多 PDE、可直接用于预训练或关键评测的数据集
才具备 S 资格。

### 负面结果与分析论文

若论文只说某模型在一个任务上失败，价值有限。若它跨架构或跨 PDE 家族，
控制变量明确，并给出可复用的诊断维度，则可能比普通新模型更值得阅读。

### 领域应用

特定工业或科学应用不是主要目标。只有当应用引入通用方法尚未处理的条件，
例如拓扑突变、极端多尺度、强不连续、独特边界或真实部署约束时，才上调。

## 从历史记录得到的校准例

以下例子用于解释判断原则，不应被当成关键词模板：

- `2509.13805` 的价值在于从上下文推断未显式给出的动力学，并检验跨物理
  zero-shot 泛化，属于基础模型核心问题。
- `2604.11625` 将微分算子项拆成可组合模块，直接对应方程表示与组合路线。
- `2603.04430` 是单一 NO 架构论文。以坐标扭曲建立全局交互，机制清楚，
  可进入 A，但不能进入 S。
- `2602.03915` 直接质疑图像 tokenizer 对物理场的适用性，并提出形态与幅值
  相关的表示原则，可因可复用性进入 A，但不能进入 S。

一些历史上仅列为 B/C 的论文最后仍产生了主笔记内容，说明不能只按主题等级
机械分类：

- `2507.17151`：用 PDE 残差评估无标签候选样本，形成主动选样的一般手段。
- `2507.09146`：用 Helmholtz-Hodge 分解编辑生成场，形成生成后施加结构约束的
  可迁移例子。
- `2601.11428`：跨 PDE 家族系统诊断神经算子失效，而非再提出一个普通模型。
- `2602.09708`：在频域控制扩散过程的函数正则性，使 PDE 算子在中间态上有定义。
- `2602.04139`：以学习条件分布替代多模型 ensemble，提供了横向 ML 视角。

## 常见误判

- 因标题写基础模型就直接给 S，而不检查是否由一个共享模型处理多个 PDE。
- 因普通 NO 架构可能用于基础模型，就错误地把它提升到 S。
- 因论文是 PINN 或特定应用就直接给 C，漏掉可迁移的优化、约束或表示原则。
- 把“换骨干网络”“加入注意力”“加入物理 loss”当成非平凡贡献。
- 只奖励正面性能提升，忽略系统性失败分析和重要反例。
- 看到陌生术语便高估新颖性，或看到熟悉组件便忽略它服务的新目的。
- 把所有略有价值的论文都收入 C。C 也必须有清楚的潜在阅读价值，但不应为了
  控制入选比例而排除满足这一条件的论文。
