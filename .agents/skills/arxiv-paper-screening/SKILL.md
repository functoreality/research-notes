# arXiv 论文初筛

## 任务目标

从已经经过推荐系统初筛的论文中，预测哪些论文最可能在后续
`paper-to-notes` 分析后产生值得记录的内容，并按阅读优先级分为
S、A、B、C。没有足够价值的论文不进入列表。

这一步追求的是阅读决策质量，不是论文质量的通用排名，也不是按主题
相似度排序。主笔记中可迁移的技术要素权重最高，但战略性证据、重要负面
结果、系统 benchmark 和公开数据集也可能具有高价值。

开始判断前，必须阅读
[references/preference-model.md](references/preference-model.md)。其中记录了
本项目的研究方向、历史偏好和容易误判的情形。

## 输入处理

常见输入是多篇论文的标题、摘要和标题链接。标题链接中通常含 arXiv ID。

- 从链接或正文提取 arXiv ID，去掉 `v2` 等版本后缀，并合并重复条目。
- 以用户提供的标题和摘要为主要依据。不要仅凭标题中的关键词分级。
- 若只有 arXiv ID，访问官方摘要页补齐标题和摘要。
- 若摘要缺失、含义不清，或宣传性措辞可能掩盖实际贡献，只对可能影响
  S/A 判断的论文进一步查看引言、方法概览或实验设置。
- 默认不通读正文。初筛不应退化成对每篇论文执行一次 `paper-to-notes`。
- 某篇论文无法可靠取得摘要时，保留不确定性，不得虚构贡献。

## 判断方法

先快速浏览全部条目，形成列表内的整体尺度，再逐篇判断。对每篇论文，
从标题和摘要中提取一至三个可能值得迁移的技术要素，并回答：

1. 它解决的问题与当前研究主线有多直接？
2. 它是否可能补充笔记中的目的手段框架，而不只是换了一个应用对象？
3. 其手段是否新颖、可迁移且非显然组合？
4. 摘要是否给出足够具体的机制、实验范围、理论或数据证据？
5. 相对笔记已有内容，它更可能带来新分支、重要对照，还是重复实例？
6. 考虑阅读成本和判断不确定性后，预期收获是否仍然足够高？

这里只需做粗粒度的目的手段判断，不必构造完整链条。不要因“不熟悉”自动
提高优先级，也不要因某篇论文容易理解而自动降低优先级。

### 分级

等级是绝对判断，不设固定名额。S 应保持稀缺，但不得为了稀缺而机械降级。

- **S：一定要看。** 高概率影响当前核心研究方向，或很可能提供多个重要、
  可迁移的技术要素。典型情形包括实质性的 PDE/ODE 基础模型、多方程或
  跨系统学习、方程表示与组合、上下文学习、预训练和零样本泛化，以及会
  改变研究判断的系统证据。仅在摘要给出具体机制或可信证据时进入 S。
- **A：有时间优先看。** 很可能至少提供一个值得写入主笔记的要素，或提供
  与研究主线直接相关的重要架构、训练、数据、优化、理论、benchmark、
  负面结果或公开数据资源。它可能不够核心、不够广，或仍有一项关键不确定性。
- **B：进一步有时间再看。** 存在明确的潜在价值，但贡献较窄、较增量、
  适用条件较强，或仅有中等概率产生可迁移要素。通常值得形成文献笔记，
  是否进入主笔记尚不确定。
- **C：时间宽裕时才看。** 与研究相关且不是零价值，但更像局部应用、标准
  组件组合、普通 PINN/NO 变体，或只有一个低置信度的孤立想法。
- **不列入。** 没有可辨认的技术迁移价值，与研究方向只有表面关键词重合，
  与已有内容高度重复且没有新证据，或贡献描述过于空泛，阅读收益不足。

### 校正规则

- `foundation model`、`universal`、`physics-informed` 等词本身不构成高等级。
  检查是否真的跨方程、跨物理、跨条件或跨任务，及其泛化如何实现。
- 新网络模块或更低误差本身通常不够。优先看它揭示了什么一般问题，或提供了
  哪种可复用机制。
- 特定应用论文通常降级。若极端尺度、几何、边界、数据或失效情形暴露了通用
  瓶颈，可重新上调。
- 严谨的失效分析、负面结果和反例可以高于提出普通新模型的论文。
- 综述只有在建立新的决策框架、定量规律或战略判断时才进入高等级。
- 公开且相关的数据集可因预训练或 benchmark 价值进入 A。若覆盖面、规模或
  变量设置对 PDE 基础模型具有独特价值，可进入 S。
- 作者、机构和会议只用于调整可信度，不能替代对贡献本身的判断。
- 摘要看似有趣但证据明显单薄时，下调一级，并在理由中指出不确定来源。

## 输出

在用户指定位置写 Markdown。若未指定，写入当前项目的 `personal-notes/`。
文件名优先采用 `arxiv-YYMMDD.md`，日期取推荐列表日期或当前日期。若同名文件
已经存在，不得覆盖，改用 `arxiv-YYMMDD-screened.md` 或请求用户指定名称。

沿用个人笔记的紧凑大纲格式：

```markdown
* S：一定要看
	* 2603.04430 [Flowers: A Warp Drive for Neural PDE Solvers](https://arxiv.org/abs/2603.04430)
		* 理由：以坐标扭曲构造线性复杂度的全局交互，可能形成新的 NO 架构分支。
* A：有时间优先看
	* ...
* B：进一步有时间再看
	* ...
* C：时间宽裕时才看
	* ...
```

要求：

- 各等级内也按预期价值从高到低排序。
- 每篇保留 arXiv ID、标题、官方链接和一句具体理由。
- 理由说明“可能补充什么或改变什么判断”，避免复述摘要。
- 默认不列出被排除论文，只在文末写 `* 未列入：N 篇`。
- 若用户需要复核，再追加被排除清单及简短理由。
- 不输出伪精确的数值评分。边界判断可标注“接近 S”或“接近 A”，但仍须给出
  唯一等级。

## 与后续 Skill 的边界

初筛完成后停止，不自动对 S/A 论文运行 `paper-to-notes`。用户选定论文后，
再用后者检查笔记覆盖、展开目的手段链、验证数据集并形成迁移计划。
