# arXiv 论文初筛

## 任务目标

从已经经过推荐系统初筛的论文中，预测哪些论文最值得继续阅读，并按
S、A、B、C 排列。名单服务于时间稀缺时的阅读决策，不是尽量收全论文。
入选数量由每篇论文的绝对预期价值决定，不设保留比例、名额或覆盖率目标。
候选多且各自补充不同问题时可以多列，大多数候选不相关时可以只列很少，甚至
不列。没有足够价值的论文不进入名单。

这一步追求的是用户查看名单的投入产出比，不是论文质量的通用排名，也不是
按主题相似度排序。历史人工分级反映时间稀缺时的主观优先级；论文后来是否
进入 `raw/` 只用于判断它是否确有内容价值，不能单独决定优先级。

开始判断前，必须阅读
[references/preference-model.md](references/preference-model.md)。其中记录了
本项目的研究方向、历史偏好和容易误判的情形。

## 输入处理

常见输入是多篇论文的标题、摘要和标题链接。标题链接中通常含 arXiv ID。

- 从链接或正文提取 arXiv ID，去掉 `v2` 等版本后缀，并合并重复条目。
- 以用户提供的标题和摘要为主要依据。不要仅凭标题中的关键词分级。
- 若只有 arXiv ID，访问官方摘要页补齐标题和摘要。
- 若摘要缺失、含义不清，或宣传性措辞可能掩盖实际贡献，只对可能影响
  S/A 判断的论文进一步查看引言、方法概览或实验设置。
- 默认不通读正文。初筛不应退化成对每篇论文执行一次 `paper-to-notes`。
- 某篇论文无法可靠取得摘要时，保留不确定性，不得虚构贡献。

## 判断方法

先快速浏览全部条目，再按两层顺序判断。不得把多个软指标相加后越过论文大类
的等级上限。

### 第一层：确定大类与等级上限

1. 多 PDE/ODE 系统的基础模型及其直接研究：候选 S。这里也包括两种形式：
   可重组为新 PDE 求解器、无需对整 PDE 重训的算子项模块库；直接解释
   跨系统预训练、in-context 泛化或迁移机制的研究；基础模型的数据构成、
   scaling law 与算力规划；训练阶段不绑定方程、推理时才注入不同 PDE
   的共享模型。
2. 可公开使用、对多 PDE 预训练或评测有直接价值的数据集或 benchmark：
   候选 S。
3. 普通神经算子、单 PDE 通用模型、PINN、数值方法与一般 ML 方法：最高 A。
4. 与 PDE 无关的基础模型：通常不列入。不能因标题含 `foundation model`
   而进入名单。

### 第二层：在大类内判断

对每篇论文，从标题和摘要中提取一至三个可能值得迁移的技术要素，并回答：

1. 它解决的问题与当前研究主线有多直接？
2. 它是否可能补充笔记中的目的手段框架，而不只是换了一个应用对象？
3. 其手段是否新颖、可迁移且非显然组合？
4. 摘要是否给出足够具体的机制、实验范围、理论或数据证据？
5. 相对笔记已有内容，它更可能带来新分支、重要对照，还是重复实例？
6. 考虑阅读成本和判断不确定性后，预期收获是否仍然足够高？

类内先采用以下基线，再根据贡献上下调整：

- 普通神经算子以 B 为基线。只有直接解决表示、跨离散泛化、规模、数据或
  长时稳定性等核心瓶颈，并给出可迁移的非平凡机制时才升 A。
- PINN 及其常规训练改进以 C 为基线。只有机制明显超出单篇 PINN，能迁移到
  神经算子、优化或一般 ML 框架时才升 B 或 A。
- 特定应用以不列入或 C 为基线。应用中的极端条件确实暴露通用瓶颈时才上调。
- 把多个标准组件组合起来解决已知问题，通常不足以升 A。

这里只需做粗粒度的目的手段判断，不必构造完整链条。不要因“不熟悉”自动
提高优先级，也不要因某篇论文容易理解而自动降低优先级。

整体浏览只用于发现重复、判断相对优先级和识别边界项，不能反过来为控制入选
数量而淘汰一篇本来值得读的论文。反之，也不要为使列表看起来完整而收入价值
尚不明确的 C。

### 分级

等级是绝对判断，不设固定名额或预期保留率。列表结束后可以回看边界项以排除
重复或价值被高估的条目，但不得只因入选比例偏高而降级或删除。最终名单的长短
本身是筛选结果，不是需要优化的指标。

- **S：一定要看。** 只允许两类论文进入：一是一个共享模型能处理多个不同
  PDE、ODE 系统或物理系统，及直接研究这类模型的表示、预训练、迁移、
  扩展和失效；
  二是可公开使用、适合多 PDE 预训练或关键 benchmark 的数据集。对确属
  第一类的论文偏重召回，通常收入 S，避免漏掉核心工作。
- **A：有时间优先看。** 延后阅读可能影响近期 PDE 基础模型研究决策，或
  很可能提供一个与主线直接相关的重要架构、训练、数据、优化、理论、
  benchmark、负面结果或公开数据资源。仅仅可能写入主笔记不足以进入 A。
  普通神经算子即使非常新颖，也最多进入 A。论文已经通过总入选关，且属于
  重要 NO、优化或反问题技术时，A/B 难分可选 A。
- **B：进一步有时间再看。** 存在明确的潜在价值，但贡献较窄、较增量、
  适用条件较强，或仅有中等概率产生可迁移要素。通常值得形成文献笔记，
  是否进入主笔记尚不确定。
- **C：时间宽裕时才看。** 与研究相关且不是零价值，但更像局部应用、标准
  组件组合、普通 PINN/NO 变体，或只有一个低置信度的孤立想法。
- **不列入。** 没有可辨认的技术迁移价值，与研究方向只有表面关键词重合，
  与已有内容高度重复且没有新证据，或贡献描述过于空泛，阅读收益不足。

### 校正规则

- 判断 PDE 基础模型时，检查同一组共享参数是否处理多个不同 PDE 或物理系统，
  而不是仅在同一 PDE 下改变初边值、系数或区域。后者按普通神经算子判断，
  最高 A。
- 必须区分“同一组权重联合学习多个 PDE”和“在多个 PDE benchmark 上分别
  训练同一种架构”。只有前者具备 S 资格；摘要不清楚时应定向查看方法或
  实验设置后再决定。
- 地球物理、气象等领域模型若实际只覆盖一个 PDE 或固定方程组，不属于本 Skill
  所说的多 PDE 基础模型。视频、表格、天文等非 PDE 基础模型通常不列入。
- 普通神经算子架构可能被未来基础模型采用，不等于它本身是基础模型研究，
  不能进入 S。
- 可复用的算子项模块若能跨 PDE 重新组合，并免去对新 PDE 整体重训，属于
  基础模型核心路线；只在固定 PDE 内做 operator splitting 不属于此类。
- 模型若在训练阶段不绑定具体方程，并在推理时通过残差、上下文或条件处理
  多种未见 PDE，也具备 S 资格，即使论文没有使用“基础模型”一词。
- 直接研究跨系统基础模型为何能预训练、in-context 泛化或迁移的论文可进入
  S，即使为隔离机制而采用小模型。泛泛研究某模型的 OoD 性能不属于此类。
- 直接研究多 PDE 基础模型的数据需求、scaling law、训练或部署成本，若结论
  会影响基础模型建设决策，也可进入 S。
- `foundation model`、`universal`、`physics-informed` 等词本身不构成高等级。
- 新网络模块或更低误差本身通常不够。优先看它揭示了什么一般问题，或提供了
  哪种可复用机制。
- 特定应用论文通常降级。若极端尺度、几何、边界、数据或失效情形暴露了通用
  瓶颈，可重新上调。
- 严谨的失效分析、负面结果和反例可以高于提出普通新模型的论文。
- 综述只有在建立新的决策框架、定量规律或战略判断时才进入高等级。
- 公开且相关的数据集可因预训练或 benchmark 价值进入 A。若覆盖面、规模或
  变量设置对 PDE 基础模型具有独特价值，可进入 S。
- 公开的单 PDE 数据集若规模、精度或任务设置具有明显稀缺性，通常进入 A；
  普通小型数据集进入 B 或不列入。
- 作者、机构和会议只用于调整可信度，不能替代对贡献本身的判断。
- 摘要看似有趣但证据明显单薄时，下调一级，并在理由中指出不确定来源。

## 输出

在用户指定位置写 Markdown。若未指定，写入当前项目的 `personal-notes/`。
文件名优先采用 `arxiv-YYMMDD.md`，日期取推荐列表日期或当前日期。若同名文件
已经存在，不得覆盖，改用 `arxiv-YYMMDD-screened.md` 或请求用户指定名称。

输出是供用户快速扫读的索引，不是分析报告。沿用个人笔记的紧凑大纲格式：

```markdown
* S
	* 2509.13805 多物理上下文学习基础模型
* A
	* 2603.04430 NO 用坐标扭曲实现全局交互
* B
	* ...
* C
	* ...
```

要求：

- 各等级内按预期价值从高到低排序。
- 某等级没有论文时，省略该等级，不写“无”。
- 每篇只写 arXiv ID 和一个有助于回忆判断依据的极短说明。
- 不写论文标题、作者、链接、数值评分、分级论证或被排除论文数量。
- 能从 arXiv ID 和短说明推断的信息不再展开。
- 若用户明确要求复核，再另行输出详细理由和被排除清单。

## 与后续 Skill 的边界

初筛完成后停止，不自动对 S/A 论文运行 `paper-to-notes`。用户选定论文后，
再用后者检查笔记覆盖、展开目的手段链、验证数据集并形成迁移计划。
