	* 监督学习；{n3bg39}
		* 有监督任务（SL）可以用无监督（极大似然，MLL）框架的方法完成：{n32e03}
			* 分类，刻画 $p(x,y|\theta)$ 联合概率即可，使用时 $p(y|x,\theta)$ 不难求；{o31e9h}
				* 相关：((o31e9g))多分类任务引入假类别可提高性能，((o31f2h))数据增强-mixup，((n9nb1u))生成模型--classifier-free guidance
			* 回归，使用前向网络 $f_\theta$ 构造概率模型 $p(y|x,\theta)=(y-f_\theta(x))^2$
			* 从而预测 $x\mapsto y$ 问题成为有缺失数据的补全 $(x,y=?)$ 问题
			> SL 任务都可转化为 MLL 任务，这个意义下 SL $\subset$ MLL；能处理 MLL 的方法也能用于求解 SL，这个意义下 MLL $\subset$ SL；试图形式化说明这两种解读关系的尝试未成功
			* 注意 MLL 框架的解用于回归问题，也可以是 $f_\theta(x)=\mathbb{E}p(y|x)$ 形式，未必极大后验
			* 不是所有的可用于 SL 的方法都来自 MLL 框架：有的方法只描述 $p(y|x)$ 而不描述 $p(x)$，例如 k-means 等
				* 此时 MLL 框架相当于多学了（推断用不上的）额外信息 $p(x)$
				* 这种额外信息有时有用，例如 `metaModelUniv:`(metaL) 中用 argmin 描述的 $g:D^s\mapsto p\mapsto h$ 映射类比直接 $D^s\mapsto h$ 更广
		* 元学习从理论上也可采用有监督形式((n3gd6h))，此时架构通常为 hypernet

			* DRQN 结合了 RNN 表达这一非 Markov 的状态转移方式，相当于状态空间为 $(o_1,\dots,o_t)$（观测 $o$ 作为状态 $s$ 的替代），或者将 RNN 的隐状态作为学出来的状态空间表达；例子见 2021-04-07 AISC 讨论
			* `2010.15761`（用 RL 设计方程求解迭代算子）认为非完整观测情形，引入 recurrent belief state（相当于记忆项）后可按有完整观测 MDP 处理

	* 流形学习思路汇总；{n32f1h}
		* 维数估计：
			* neural empirical Bayes technique 离散数据按大小 $L$ 的噪声填充 gap 后，局部 PCA 求维度，最后汇总不同的 $L$ 情形
				* eg. `AI-Poincare-2011.04698`(MR)“流形学习”，DAE（denoising AE）
				* 局部 PCA 步骤 1：训练 NN 表达向流形的压缩映射
				* 步骤 2：局部采样点，方法为从某个流形上初始点出发，随机移动-用 NN 拉回流形，重复多步
			* 分形方法，kNN 半径关于 $k$ 的增长速度，维数可能非整数
			* AE，最小隐空间维数，可能逐个设置维数试拟合效果，或者在隐空间加 L1 正则化保稀疏性
				* 拓扑复杂的流形可能维数估计不对，如 `AI-Poincare-2011.04698`(MR)“需要额外的维度”
			* AD，适合无穷维空间
		* 流形结构表达：
			* AE（同维数估计，不适合非平凡拓扑），AD（`GLO-1707.05776` 用于条件生成时类似？）
		* 需表达映射 $x\mapsto y$，利用定义域为（未知）流形的结构：
			* kNN，属于 lazy-learning，用邻域数据 $x_i$ 线性组合拟合 $x$，从而用 $y_i$ 组合估计 $y$
				* eg. `2011.00568` PDE 区域分解之后，表达单区域的解算子；认为解流形低维
		* 相关：数据用流形学习找出一维参数化，作为伪时间，从而数据可按时序处理 `2106.12430` 最后一个实验
			* 双时间尺度 SDE 有“不变流形”概念，用于降阶建模得慢尺度 SDE `Auto-SDE-2205.04151`
			* 图像有 patch manifold，((n32d8v))PDE区域分解 有可能涉及类似的东西
		* 函数空间中的流形？
			* patch/slice manifold：单个场本为函数空间中一点，通过限制产生一系列（定义域较小的）场；{n5bf17}
				* 相关：((n5bf11))单任务hypernet（patch 对应分类、slice 对应回归）
				* patch manifold 参数化，可导出((n4ta1s))INR-区域分解-各区域仅维护独立隐向量
					* 打 patch 还可涉及：((n4rm8d))tokenize，((n37m6i))ViT
					* 参数化映射架构，输入为（无结构）隐向量的 decoder 一般均可，如（无网格）INR、（有网格）CNN、ViT（直向量 reshape 为 2D grid）
					* patch 集合的另一处理方式：((n7a92o))视为 graph、按 feature vec kNN 连边
					* 区分 patch 边界连续移动、离散移动（即切分为若干不重叠 patch）
						* COIN++ step1 训练 patch manifold 的参化映射时 patch 连续移动，step2 对各 patch 找其对应参数时 patch 离散移动((_p59b7r))
					* 对所有固定大小 patch 编码：可认为((n8hj6h))CNN 卷积操作完成了这点，patch 切分情形可通过在卷积中设定 stride 达到
					* patch size 可变，见((oapa1r))空间分辨率压缩-压缩率可变
					* 相关：((n98h1e))点云局部聚合也称为某种 patch
					* 在隐空间打 patch((o33a2v))
					* INR 的微观有网格变种，((oam965))输出为 patch 而非单点值；{oam96b}
				* slice manifold 的特例：时间 slice，含时 PDE 不同时间步 snapshot 组成流形；{n5bf2t}
					* 如((n2h89q))动力学 snapshot 用 AD 表达
					* 此时该流形上有动力学结构（不再视为纯集合）
				* 视为数据总量压缩策略，((oa3c1p))整块数据先赋予集合结构，再依据要素压缩
					* 这里为 patch/slice 集合；之后对 patch manifold 参化相当于提高维度压缩率
		* 相关：流形学习可用于((n4sl1x))提供先验；这里主要讨论高维空间流形，低维情形见((n8re3h))曲面
